# weekndr.

**Your semester abroad, all in one place.**

Weekndr is a study abroad semester planning app for college students. It will help students
view their available weekends, plan trips, track travel budgets, get personalized destination
recommendations, and organize travel with friends.

Created by **Bhavya Mudduluri**, Penn State entrepreneurship project.

## Current status

Week 1: a responsive one-page marketing website. No accounts, payments, or database yet.

## Tech stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- [Tailwind CSS](https://tailwindcss.com)
- Deployed on [Vercel](https://vercel.com)
- Photos from [Unsplash](https://unsplash.com) (Unsplash License)

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Project structure

- `src/app/page.tsx`: the homepage content
- `src/app/layout.tsx`: fonts and page title
- `src/app/globals.css`: brand colors (cream, light blue, navy) and fonts
- `src/components/Photo.tsx`: reusable photo block
